LLM Council Report

Interview Prep recovery · 2026-08-02 17:13 IST

Question

How should we recover the Interview Prep app so it matches the original product request (always-on 3-pane studio), given what was already built and the “dead page” experience?

Chairman verdict

Where the council agrees

  • The product is gated: studio only appears after selecting an interview; idle right panel uses hidden xl:block.
  • Recovery is primarily a shell/layout PR, not a backend rebuild. APIs/DB/voice hooks largely exist.
  • Always mount left + banner + center + right; empty states live inside panes; auto-select/create a draft on load.
  • Do not start with PDF parsing, Whisper, or more runtime plumbing.

Where the council clashes

  • ADO content now: most advisors want (A) interviewer calibration only today; Expansionist wants (C) both immediately; Outsider wants (C) phased (A now, Study later).
  • Peer review unanimously called Expansionist’s “ship study library now” the biggest blind spot vs “keep simple / restore trust.”

Blind spots the council caught

  • Voice UX (listen / type-suppress) must be verified inside the ungated studio.
  • Auto-draft lifecycle (orphan drafts, history clutter, refresh races).
  • Center-column IA audit: question → answer under → blue EVALUATION → follow-ups → code pane beside.
  • Runtime fallback (Cursor → OpenClaw) for the first 60 seconds after layout fix.

The recommendation

Ship one focused UI recovery PR that matches the brief literally:

  1. Always-on 3-pane studio (ungate AppShell; remove right-panel xl hide).
  2. Auto-create/select draft interview so banner uploads work on first paint.
  3. Banner spans center+right with resume | JD+URL boxes.
  4. ADO pack = live interviewer prompt / seniority calibration (A) for this phase; Study library only after the mock loop feels alive.
  5. Acceptance: open the app → see full studio with no clicks; Start → speak → answer → blue EVALUATION opens right coaching.

The one thing to do first: ungate the studio shell and always show the right coaching column.
